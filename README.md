# Sota Toggle

Переключает VPN в Sota Connect по NFC-кнопке Aaron Button (или по любому сценарию).

**Как работает:** сценарий открывает невидимое приложение Sota Toggle → служба спец. возможностей
опускает шторку → нажимает плитку Sota → закрывает шторку. Ты остаёшься в том приложении, где был.
Шторка мелькнёт примерно на секунду. Совсем без визуала на Android так не сделать.

---

## 1. Собрать APK на GitHub

1. Зайди на github.com → **+** (вверху справа) → **New repository** → любое имя, можно **Private** → **Create repository**.
2. На странице репозитория нажми **uploading an existing file**.
3. Перетащи **содержимое** папки `SotaVpnToggle`: `.github`, `app`, `build.gradle`, `settings.gradle`,
   `gradle.properties`, `README.md`. Перетаскивай не саму папку, а то, что внутри. Нажми **Commit changes**.
4. Проверь, что загрузилась папка `.github`. Она скрытая: на macOS в Finder её показывает Cmd+Shift+. ,
   а с телефона она часто не выбирается. Если её нет: **Add file → Create new file**, в имя впиши
   `.github/workflows/build.yml`, вставь содержимое этого файла из архива и сохрани.
5. Открой вкладку **Actions**. Сборка запустится сама; если GitHub попросит включить Actions, разреши.
   Сборка идёт 3–5 минут.
6. Когда появится зелёная галочка, открой запуск. Внизу, в блоке **Artifacts**, нажми **SotaToggle-apk**.
   Скачается zip, внутри `app-debug.apk`.

Чтобы пересобрать вручную: **Actions → Build APK → Run workflow**.

## 2. Установить и включить

1. Перекинь `app-debug.apk` на телефон, открой его и разреши установку из неизвестных источников.
2. **Настройки → Специальные возможности → Установленные приложения → Sota Toggle → включить.**
3. Если переключатель серый или появилось «Ограниченная настройка»: **Настройки → Приложения → Sota Toggle →
   ⋮ (вверху справа) → «Разрешить ограниченные настройки»**, затем повтори шаг 2.
4. Плитку Sota в шторке лучше поставить на **первую страницу** быстрых настроек (карандаш редактирования панели).
   С других страниц приложение тоже попробует её найти, но первая страница надёжнее.

## 3. Проверить

Долгое нажатие на иконку **Sota Toggle → «Настройки» → «Тест: переключить VPN»**.

- ✅ — всё работает.
- ❌ «Плитка не найдена» — внизу будет список подписей, которые видны в шторке. Найди среди них плитку
  соты, впиши её название (или часть) в поле, нажми «Сохранить» и повтори тест. По умолчанию ищется `Sota`.

## 4. Назначить на Aaron Button

В **«Режимах и сценариях»** (или в приложении Aaron Button) в действии выбери
**«Открыть приложение» → Sota Toggle**. Каждое нажатие переключает VPN: выключен → включится, включён → выключится.

У приложения есть ярлыки **«Включить VPN»** и **«Выключить VPN»**. Если они появятся в
«Открыть приложение или выполнить действие», ими можно сделать кнопку, которая только включает.

## Если что-то не так

- **Служба сама выключается:** Настройки → Приложения → Sota Toggle → Батарея → **«Без ограничений»**.
- **Ставишь новую сборку поверх старой, а она не устанавливается:** каждая сборка на GitHub подписана новым
  тестовым ключом. Удали старую версию, установи новую и снова включи службу.
- **Нажимается не то:** укажи в настройках более точный текст плитки, например `Sota Connect`.
